# Privacy Policy — PR Sidebar

- Your GitHub token and settings are stored locally in your browser (`storage.local`). They never leave your machine except as described below.
- The token is sent only to GitHub (`api.github.com`) to list your open pull requests and their status.
- Avatar images for PR authors other than you are loaded from GitHub's avatar CDN (`avatars.githubusercontent.com`). No token or identifying data is attached to those requests.
- No other network requests are made. No analytics, no tracking, no third-party services.
- The `tabs` permission is used only to highlight and focus the browser tab matching a pull request; no browsing data is collected or transmitted.
